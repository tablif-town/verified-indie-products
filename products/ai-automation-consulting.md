# AI & Automation Consulting

AI infrastructure, DevOps automation, and LLM workflow consulting.

- **Site:** [consultant.quinnfavo.com](https://consultant.quinnfavo.com/)
- **Topic:** [Developer](../topics/developer.md)
- **Ownership verified:** 2026-10-21

FlickDeck provides automation builders with a watch-native shortcut for smart home scenes, desk setups, and homelab tasks. It allows users to run webhooks or Home Assistant automations from a Wear OS watch using deliberate wrist movements like a double twist, flick up, or flick down. Gesture listening only activates when armed, preventing accidental triggers during daily wear. The tool features haptic feedback, gesture test modes, and profiles for custom workflows.
