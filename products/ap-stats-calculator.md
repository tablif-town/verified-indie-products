# AP Stats Calculator

Free AP Statistics calculators with step-by-step solutions

- **Site:** [apstatscalculator.com](https://www.apstatscalculator.com/)
- **Topic:** [Desktop and utilities](../topics/desktop-and-utilities.md)

AP Stats Calculator is a free suite of online calculators built for AP Statistics students and teachers: binomial distribution, normal distribution, z-score, p-value, t-test, chi-square, confidence intervals, regression and an AP score calculator — each with step-by-step explanations, formulas and worked examples. No sign-up needed.

## What it does not do

- It doesn't allow students to use the website during the actual AP Statistics exam.

  > Can I use this website during the AP Statistics exam?

- It doesn't provide the exact official score cutoffs because the College Board adjusts them annually.

  > the College Board does not publish exact cutoffs each year, so they can shift a little.

- It doesn't offer a downloadable version for offline use as it is a browser-based tool.

  > An Ap Stats Calculator is a free browser tool that runs every statistical function on the AP® Statistics exam.
