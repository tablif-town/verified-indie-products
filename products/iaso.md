# iASO

Free open-source ASO keyword research tool for macOS

- **Site:** [github.com/orlandonanditonehemia/iASO](https://github.com/orlandonanditonehemia/iASO)
- **Topic:** [Marketing and sales](../topics/marketing-and-sales.md)

Free, open-source alternative to TryASO, AppFollow & Sensor Tower built natively for macOS. • Keyword scoring : Popularity, Difficulty & Opportunity from iTunes Search API • Competitor Research : extract rival app's keyword strategy via AI • AI Name Generator : App Name + Subtitle + Keyword Field within ASC limits No subscription. No account. Just clone & run.
