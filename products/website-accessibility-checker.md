# Website Accessibility Checker

Free WCAG 2.2 & ADA website compliance audit tool.

- **Site:** [websiteaccessibilitychecker.net](https://websiteaccessibilitychecker.net/)
- **Topic:** [Work and office](../topics/work-and-office.md)
- **Ownership verified:** 2026-10-28

An automated accessibility scanner powered by axe-core & Pa11y. Get a detailed report on WCAG 2.2 AA and ADA Title III compliance issues with exact code snippets to fix them. No fluff, just actionable data for developers and agencies.

## Quick answers

Each answer comes with the sentence it is based on, quoted from the product's own pages.

### Can I audit public web pages instantly?

Yes, you can paste public web addresses directly into the tool without signing up or installing extensions.

> Paste any public web address into the scanner.

### How long do audit reports stay active?

Generated reports and their permanent links remain active and accessible for 24 hours.

> Fair-use protection • Reports active for 24h

### How does the scanner test live web pages?

The scanner renders pages in a headless browser and uses both axe-core and Pa11y in parallel to test over 50 rules.

> The page is rendered in a headless browser, then analyzed in parallel by axe-core (Deque) and Pa11y.

### How many audits can I run for free?

Up to 10 audits in a 24-hour window.

> 10/10 audits remaining per 24h

### Which accessibility laws can the report follow?

Nine jurisdictions, including the ADA in the US, AODA in Ontario, the EAA in the EU, the UK Equality Act and laws in Australia, India, Japan, Saudi Arabia and Brazil.

> Pick from 9 supported jurisdictions; the report card and the exported PDF follow your choice.

### Which engines run the checks?

Two open engines, axe-core from Deque and Pa11y, run on the same rendered page.

> analyzed in parallel by axe-core (Deque) and Pa11y

### Do I need to install a browser extension?

No. You paste a web address and the scan runs on the site, with no extension or code to install.

> no browser extension or code installation required

### Can it check pages built with JavaScript?

Yes. JavaScript-rendered pages are on the list of what it scans, because each page is rendered in Chrome before the rules run.

> JavaScript-rendered pages

### Can I test raw HTML or an email template?

Yes. The HTML Accessibility Issues Detector takes pasted HTML, CSS or an email template and audits it on its own.

> Paste raw HTML, CSS or an email template for an isolated static audit.

### Do I need to install a browser extension or add code to my site?

No. You paste a public web address into the scanner and it runs the audit without any extension or code installation.

> no browser extension or code installation required.

### Can the report follow a law outside the United States?

Yes. You can pick from 9 jurisdictions, including the EU, UK, Canada and Australia, and the report card and exported PDF follow that choice.

> Pick from 9 supported jurisdictions; the report card and the exported PDF follow your choice.

## What it does not do

- It doesn't allow unlimited scans. The free tool gives 10 audits per 24 hours.

  > 10/10 audits remaining per 24h

- It doesn't keep reports around. Each report stays active for 24 hours, so save what you need.

  > Reports active for 24h

- It doesn't check a PDF completely on its own. 47 of the 136 Matterhorn Protocol checkpoints are automated, and the rest are listed for a person to verify.

  > PDF audits cover 47 of the 136 Matterhorn Protocol checkpoints automatically

- It doesn't audit pages behind a login. You give it a public web address.

  > Paste any public web address into the scanner.
