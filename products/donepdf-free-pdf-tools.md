# DonePDF – Free PDF Tools

Free online PDF tools. No signup. No watermark.

- **Site:** [donepdf.com](https://donepdf.com/)

DonePDF is a free online toolkit for working with PDF files. It lets you compress, merge, split, edit, protect, and convert PDFs without creating an account or adding watermarks. Built for quick, private, and simple document workflows.

## Quick answers

Each answer comes with the sentence it is based on, quoted from the product's own pages.

### Does DonePDF require account registration?

DonePDF allows users to process documents without creating an account. Most tools run directly in your web browser without sign-up.

> It offers more than 80 free tools to convert, compress, merge, split, edit, secure and enhance PDF files, with no sign-up and no watermark.

### Does DonePDF use uploaded files to train AI?

No, DonePDF does not read, sell, or use uploaded user files to train artificial intelligence models.

> We do not sell your files, read them or use them to train AI.

### Can DonePDF be used on mobile devices?

Yes, DonePDF works on mobile devices. You can access the tools using modern mobile web browsers on Android and iOS smartphones and tablets.

> The website and the tools work on smartphones and tablets with current versions of Android and iOS.

### Does DonePDF cost anything?

No. Every tool is free and the files you download carry no watermark.

> Yes. All tools are free to use, with no registration and no watermark.

### Which tools send my file to a server?

Only a few: Office conversions both ways, PDF to CSV, PDF to PDF/A, Repair PDF, OCR PDF and Image to Text. Merge, split, compress, rotate, watermark, protect and unlock run in your browser.

> the tools that need it - Word to PDF, Excel to PDF, PowerPoint to PDF and Word URL to PDF

### How long does a file sent to the server stay there?

It is deleted right after processing, and never later than one hour. The connection is encrypted on the way up.

> deleted right after processing, and in every case no later than one hour

## What it does not do

- It doesn't allow unlimited file sizes for server-side tools like OCR and Office conversions.

  > Tools that convert on our server (OCR and Office conversions) have an upload limit; if a file is too large, the tool tells you.
