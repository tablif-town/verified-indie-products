# Jot 2.0

Select text, tap Shift twice, it's a markdown file

- **Site:** [sayjot.xyz](https://sayjot.xyz/)
- **Topic:** [Personal](../topics/personal.md)
- **Ownership verified:** 2026-11-13

Jot is a capture inbox for macOS. Select anything, tap Shift twice, and it becomes a markdown file in a folder you own. Hold fn to dictate into any app. Ctrl+Opt+A grabs a region of the screen to mark up. Jot 2.0 is rewritten in Rust, off Electron: 675 MB down to 43 MB on Apple silicon. No account, no sync. Speech runs on your Mac with 59 local models. A CLI and an MCP server let Claude Code, Codex and Cursor read, search and tag your notes. One-time license.
