# DevTools Hub

163 free dev tools that never leave your browser

- **Site:** [devstoolshub.com](https://www.devstoolshub.com/)
- **Topic:** [Developer](../topics/developer.md)
- **Ownership verified:** 2026-10-22

Free online developer tools: UUID generator, JWT decoder, JSON formatter, password generator and more. Everything runs in your browser — your data never leaves your device.

## Quick answers

Each answer comes with the sentence it is based on, quoted from the product's own pages.

### Is there an API I can call from my own backend?

Not yet. A public API for teams is listed as a longer-term plan, along with an optional Pro tier.

> a public API for teams that want these utilities in their own backends

### Can I format and validate SQL with it?

Yes. The SQL Toolkit can format, validate, minify and diff SQL, and give index advice.

> Format, validate, minify, diff, index-advise, and explain SQL

### Does it have tools for Docker Compose files?

Yes. The Docker Toolkit validates, lints, formats and visualizes Compose files and lints Dockerfiles.

> Validate, lint, format, visualize, merge, and resolve Docker Compose files, and lint Dockerfiles

### Can I verify a JWT signature, or only decode it?

Both. The JWT toolkit has eight tools that decode, explain, verify and build tokens, and the site says nothing you paste into them is sent anywhere.

> Everything for working with JSON Web Tokens, in one place — decode, understand, verify, build, and secure them.

### Can I test an AWS IAM policy before I deploy it?

Yes. The AWS toolkit can generate, review, simulate and minify IAM policies. It also parses ARNs, validates tag policies and checks CloudFormation templates.

> Parse and build ARNs, generate, review, simulate, and minify IAM policies, validate tag policies, look up Regions, and validate CloudFormation templates

### Can it find secrets left in a GitHub Actions workflow?

Yes. The GitHub Actions toolkit validates, lints and visualizes workflow files, and one of its four tools audits them for secrets.

> Validate, visualize, lint, and audit secrets in GitHub Actions workflows — four tools covering correctness and security.

### Is my data sent anywhere when I use a tool?

No. Every tool runs locally in your browser, and your data never touches a server.

> Every tool runs locally in your browser; your data never touches a server.

### Are the tools free?

Yes. DevTools Hub is a set of free tools for developers.

> Free tools for developers

### Can I compare two JSON files?

Yes. The JSON Toolkit can diff JSON, along with formatting, validating, minifying and converting it.

> Format, validate, diff, minify, convert, query, and schema-generate/validate JSON

### Is there an API I can call from my own backend?

Not yet. A public API for teams is listed as a longer-term plan, so for now the tools are used in the browser.

> a public API for teams that want these utilities in their own backends.

### Does it save my history or favorite tools?

No. History and favorites are planned for an optional Pro tier that does not exist yet.

> Longer-term plans include an optional Pro tier (history, favorites, no ads)

## What it does not do

- It doesn't offer a public API yet; one is listed as a longer-term plan.

  > Longer-term plans include an optional Pro tier (history, favorites, no ads) and a public API

- Its YAML tools don't validate against a schema; they check syntax, duplicate keys and indentation.

  > schema-agnostic, for any YAML file

- Its regex tools don't target engines other than JavaScript.

  > Build, test, visualize, debug, and escape for JavaScript regular expressions
