# everyagent.si

The Global Super Intelligence AI Agent & MCP Registry

- **Site:** [everyagent.si](https://everyagent.si/)
- **Topic:** [AI and agents](../topics/ai-and-agents.md)
- **Ownership verified:** 2026-10-21

EveryAgent.si is the global directory, benchmark matrix, and swarm registry for autonomous AI agents & MCP servers. Key Highlights: • Continuous Auto-Discovery: Continuously ingests and verifies trusted AI agents & MCP servers worldwide. • Submit Your Agent: Community-driven indexing allows developers to feature custom agents instantly. • Live MCP Execution Harness: Interactively test MCP tool schemas in-browser. • Dynamic SI Benchmarking & Swarm Dispatcher for agent chaining.

## Quick answers

Each answer comes with the sentence it is based on, quoted from the product's own pages.

### Can I test an MCP tool before using it?

Yes. The Live MCP Execution Harness lets you test MCP tool schemas in the browser.

> Live MCP Execution Harness: Interactively test MCP tool schemas in-browser.

### How can I sort the agents?

You can sort by featured and trending, SI Score, GitHub stars, alphabetically or by newest release.

> Newest Release

### Can I filter for open-source agents only?

Yes. The directory has filters such as Open Source Only and MCP Compliant Only, plus categories like coding, deep research and security.

> MCP Compliant Only

### Can I show only agents that support MCP?

Yes. There is an MCP Compliant Only switch next to the open-source one, so you can hide everything that would need its own tooling.

> Open Source Only MCP Compliant Only

### What does each agent listing tell me?

Each card names the maker, the release year and the license, gives a one-line summary, and lists the backbone model, the architecture and the GitHub star count. Agents that support MCP carry an MCP tag.

> Backbone DeepSeek-R1 671B (MoE 37B active) Architecture

### What kinds of agents can I browse?

Eight categories, from coding and software, deep research and computer use to swarms, finance, security and DevOps, and creative and voice. You can also leave it on All Agents and see everything at once.

> All Agents Coding & Software Deep Research Computer Use & Web Swarms & Multi-Agent

### How many agents are listed?

The directory shows 316 indexed agents at the time of writing.

> 316 Agents Indexed

### How many MCP tools are in the registry?

186 MCP protocols are listed in the MCP Registry.

> 186 MCP Protocols

### How are agents benchmarked?

Against five evaluation benchmarks, shown together with each agent's SI score.

> 5 Evaluation Benchmarks

### How many agents and MCP servers are listed?

About 316 agents and 202 MCP protocols, measured across 5 evaluation benchmarks, according to the home page counters.

> 316 Agents Indexed

### Can I sort agents by popularity?

Yes. You can sort by GitHub stars, SI score, newest release, alphabetical order or featured and trending.

> SI Score (Highest) GitHub Stars
