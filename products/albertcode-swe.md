# AlbertCode SWE

AI coding agent that builds and tests code with your chosen model

- **Site:** [albertcode.dev](https://www.albertcode.dev/)
- **Topic:** [AI and agents](../topics/ai-and-agents.md)
- **Ownership verified:** 2026-10-24

AlbertCode SWE Agent is an AI coding agent that runs on your machine and turns plain-language requests into tested, reviewed code changes. It plans each change, builds it in an isolated copy of your repository, runs your tests, and checks the result for security and quality before showing you the diff. You approve the plan before any code is written and the diff before anything reaches your files. Use it from the terminal, the browser, or VS Code with any compatible hosted or local model.

## Quick answers

Each answer comes with the sentence it is based on, quoted from the product's own pages.

### Does it cost anything to start using it?

No. It installs on Windows, macOS and Linux with no account and no fee; you bring your own model key and pay that provider, or run a local model.

> AlbertCode SWE Agent is available today on Windows, macOS and Linux, with no account and no fee to start.

### Will it run on ARM Linux or Alpine?

No. Linux support is x86-64 with glibc only, so ARM boards and musl systems like Alpine are not supported.

> Linux support is x86-64 with glibc only: no ARM, no Alpine or other musl systems.
