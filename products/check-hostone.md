Check host availability from 100+ countries: free online ping, HTTP, TCP port, DNS and traceroute checks with live results on a world map. No sign-up.

## Quick answers

Each answer comes with the sentence it is based on, quoted from the product's own pages.

### Does check-host.one cost anything?

No. Every check is free, and each result gets a link you can share.

> Yes. Every check is free and needs no account, and each result gets a permanent link you can share.

### My ping failed everywhere. Is the server down?

Not necessarily. Many hosts and firewalls drop ICMP on purpose, so try TCP Ping or an HTTP check against a port you know is open.

> A failed ping does not always mean the host is down

### Do I need to create an account to run network checks?

No account creation or registration is required. Anyone can run diagnostic tests for free directly on the site.

> Every check is free and needs no account, and each result gets a permanent link you can share.

### How does the ICMP ping check measure latency?

The ICMP ping tool sends three echo requests from every chosen measurement server. It then reports latency breakdown and packet loss details.

> Sends 3 ICMP echo requests from each selected server and reports the round-trip time.

### Do embeddable widgets trigger live network checks on page load?

Widgets display a saved test result or the most recent check instead of running a live diagnostic on page load. Visitors can click a button to initiate a new check manually.

> Widgets never measure on page load, by design.

### Can I test only from servers in one country?

Yes. Pick countries or whole continents in the server list, with up to 25 servers in one check.

> Pick countries or whole continents in the server list and use up to 25 servers per check.

## What it does not do

- It doesn't keep saved result links active after 90 days.

  > Saved results are kept for 90 days. After that the link reports that it has expired rather than showing something misleading.

- It doesn't include more than 25 measurement servers in a single test run.

  > Max servers caps how many run the check, from 1 to 25.

- It doesn't automatically run live checks whenever an embedded widget renders.

  > Widgets never measure on page load, by design.
