# Verified indie products

A list of **196** new products whose owners have proven they own them, grouped by what they are for. It is rebuilt every day from [Tablif Town](https://tablif.com), where every new product launch gets an office.

Each entry has the product, its one-line description, and where to read more about it:

- **facts**: a fact sheet in this repository, with short answers, the sentence each one is based on, and links to longer reads (178 products)
- **answers**: pages that answer buyer questions, with every claim quoted from the product's own site, on [answers.delivery](https://answers.delivery) (178 products)
- **race**: the product run against three well-known names, question by question, on [darkhorsepick.com](https://darkhorsepick.com) (24 products)
- **office**: its office in Tablif Town

The whole list as data: [`products.json`](products.json).
